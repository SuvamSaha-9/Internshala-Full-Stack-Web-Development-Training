PG Life – Property Listing Webpage
A responsive property listing website developed as the **Final Project of Internshala's Web Development Training**. The project focuses on building a practical web application for browsing and displaying PG accommodations.

Features
- Responsive property listing interface
- Property cards with relevant details
- Clean and user-friendly UI
- Structured webpage layout
- Front-end and database integration concepts

Technologies Used
- HTML
- CSS
- Bootstrap
- JavaScript
- PHP
- DBMS
- MySQL
- React

Project Purpose
This project was developed to apply the concepts learned during the 8-week Internshala Web Development Training, which covered HTML, CSS, Bootstrap, DBMS, PHP, JavaScript, React and a final project.
